# docs/plan/

The **comprehensive plan and strategy** for the full portfolio of use cases, solutions,
methodologies, and industries Orama Zetta will pursue — drafted by the combined
executive team (CEO, CPO, CTO, CMO, CRO, CFO, COO) and grounded in the evidence corpus
([`../evidence/`](../evidence/), items 01–15).

> **⚠️ Internal-confidential.** These documents inherit pricing, partner detail, and
> acquisition context from evidence 07/08. Private repo only.

## How this area works

[`00-strategy-kernel.md`](00-strategy-kernel.md) is **binding**: it records the
decisions (D1–D9) — portfolio architecture, methodology waves, use-case tiers,
industries, commercial anchors, gates, metrics, operating principles. The numbered
documents elaborate the kernel per executive domain and **must not contradict it**;
genuine tensions are recorded in each doc's "Tensions for kernel review" appendix and
resolved in the kernel first.

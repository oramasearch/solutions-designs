# docs/prompts/

Research prompts used to gather evidence for this exercise — primarily **Perplexity
Deep Research** prompts. Each file contains **only the prompt text**, copy-paste ready.
The reports that come back are captured verbatim under
[`../evidence/`](../evidence/) like any other evidence.

The prompts are built on the vocabulary in [`../vocabulary.md`](../vocabulary.md)
(use case = the problem · methodology = the arranged AI methods · solution = the
methodology applied + wired to the business action) and restate those definitions
inline so they are self-contained for the research tool.

# docs/prompts/

Research prompts used to gather evidence for this exercise — primarily **Perplexity
Deep Research** prompts. Each file contains **only the prompt text**, copy-paste ready.
The reports that come back are captured verbatim under
[`../evidence/`](../evidence/) like any other evidence.

The prompts are built on the vocabulary in [`../vocabulary.md`](../vocabulary.md)
(use case = the problem · methodology = the arranged AI methods · solution = the
methodology applied + wired to the business action) and restate those definitions
inline so they are self-contained for the research tool.

## Prompts

| Prompt | Researches | Status |
|---|---|---|
| [`methodologies-deep-research-prompt.md`](methodologies-deep-research-prompt.md) | **Methodologies** — a comprehensive compendium: per-methodology dossiers (18 fields) across 22+ families, plus a component-reuse matrix, selection guide, prevalence ranking, maturity spectrum, and correctness-discipline summary. | Ready to run |
| [`use-cases-deep-research-prompt.md`](use-cases-deep-research-prompt.md) | **Use cases** — the problem layer: per-use-case dossiers (17 fields — problem statement, economic pool, entity/label/horizon decision framing, data exhaust, actionability, measurability, documented results, failure modes) across 12 business-function families, plus a master taxonomy, value & feasibility rankings, value×feasibility grid, data-exhaust map, prevalence reality-check, and failure-pattern synthesis. | Ready to run |
| [`solutions-deep-research-prompt.md`](solutions-deep-research-prompt.md) | **Solutions** — the applied layer: per-solution dossiers (18 fields — methodology composed from, correctness adaptations, business wiring for actions/systems/people, human-in-the-loop, measurement loop, operational architecture, governance, documented deployments, failure modes) across 10 solution-pattern families, plus the anatomy of a solution, correctness-adaptation catalog, methodology→solutions fan-out, action-integration & measurement-loop patterns, why-solutions-fail, and maturity ranking. | Ready to run |

Together the three prompts research the three vocabulary layers; run each in Perplexity
Deep Research and capture the returned reports under [`../evidence/`](../evidence/).

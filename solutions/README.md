# Solutions

One folder per enterprise AI solution we're designing for Orama Zetta:
`solutions/<slug>/`. Each starts life in **stage 1 — evidence & ideas** (see the
root [`README.md`](../README.md) for the staged workflow).

Start a new one by copying the template:

```sh
cp -r templates/solution solutions/<slug>
```

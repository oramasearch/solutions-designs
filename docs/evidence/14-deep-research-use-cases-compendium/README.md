## What this is

The **external Deep Research answer** to the use-cases prompt
([`../../prompts/use-cases-deep-research-prompt.md`](../../prompts/use-cases-deep-research-prompt.md)).
Per its pasted summary: executive orientation (vocabulary framing + value-concentration
headline: McKinsey $2.6–4.4T with ~75% in four functions, against BCG 2024's 26%
past-proof-of-concept adoption reality); **~140 full dossiers** across all twelve
function areas (A–L) on the 17-field template, churn anchoring; and the **seven
cross-cutting syntheses** (master taxonomy, value ranking, feasibility ranking,
value × feasibility 2×2, data-exhaust map, prevalence reality-check, failure-pattern
synthesis).

(economic pool, documented results, prevalence) repeat function-level evidence across
sibling use cases rather than entry-specific numbers — e.g. Bain retention economics
anchoring several customer/revenue dossiers. A deepening pass was offered.

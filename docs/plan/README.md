## The v2 philosophy (2026-07-15)

This plan defines the **future state** — the most complete vision of the business:

1. **No sequencing.** No waves, phases, releases, or launch tiers. The portfolio is
   *scored*, not scheduled.
2. **Future-state analysis only.** Every decision answers *"is this a good decision for
   us in the future?"* — never "where are we today?".
3. **ROI is the central metric.** Customer return on investment, risk-adjusted by
   probability of success (`score = E[ROI] × p(success)`), governs selection,
   measurement, **and pricing**. Intelligence Velocity remains a supporting metric only.
4. **Auto-RL is central.** Every solution is operated by agents trained on the
   customer's own data; methodologies are the agents' tools.
5. **Data is a designed supply chain** (the CDO dimension): every solution and
   methodology carries a data collection + refinement plan that feeds agent training —
   with measured ROI as the reward signal.

## How this area works

[`00-strategy-kernel.md`](00-strategy-kernel.md) is **binding**: it records the
decisions D1–D10. The numbered documents elaborate the kernel per executive domain and
**must not contradict it**; genuine tensions go in each doc's "Tensions for kernel
review" appendix and resolve in the kernel first.

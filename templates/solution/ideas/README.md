# ideas/

Loose ideas, hypotheses, analogies, and "what if" notes for this solution.

Everything here is **explicitly provisional** — nothing is a decision or a
recommendation. Capture the thought, note what sparked it (link back to the relevant
[`evidence/`](../evidence/) where there is any), and move on. Weighing and choosing
happens in the analysis stage, not here.

Suggested: a single `ideas.md` as a running list, or one file per theme.

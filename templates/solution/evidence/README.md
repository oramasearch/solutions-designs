# evidence/

Raw, un-interpreted input for this solution. **Collect, don't conclude.**

Drop in source material, transcripts, links, quotes, data points, screenshots, and
stated requirements. **Cite where each piece came from** (URL, person, document,
date). No analysis, editorializing, or conclusions here — that comes in a later
stage.

Suggested: one file per source (`<source-slug>.md`), or a single `notes.md` with
clearly attributed entries. Put binary/large assets alongside in this folder.

# docs/

All working documentation for the enterprise AI solution designs. Navigate down via
each subfolder's own `README.md` (progressive disclosure).

## Contents

- [`vocabulary.md`](vocabulary.md) — the governing terms **use case · solution ·
  methodology** (definitions, their relationship, and a worked churn example). Read this
  first; it's the vocabulary every other doc uses.
- [`evidence/`](evidence/) — the **verbatim** evidence, one subfolder per source/topic.
  Evidence collection remains open. → [`evidence/README.md`](evidence/README.md)
- [`prompts/`](prompts/) — the research prompts (Perplexity Deep Research) used to
  gather evidence; results land in `evidence/`. → [`prompts/README.md`](prompts/README.md)
- [`plan/`](plan/) — **the comprehensive portfolio plan & strategy** (use cases ·
  solutions · methodologies · industries), authored by the combined executive team and
  grounded in the evidence. The strategy kernel (`plan/00`) is binding; started
  2026-07-15. ⚠️ Internal-confidential. → [`plan/README.md`](plan/README.md)

_The design phase (per-solution architecture on Zetta) gets its own subfolder when we
reach it._

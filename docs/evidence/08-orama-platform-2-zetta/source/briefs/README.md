# Orama Zetta — briefs

Source material for explaining **Orama Zetta** to multiple audiences. Each brief is a self-contained, video-script-ready explainer: a logline, a tight narrative, talking points, a line or two worth saying, and visual beats ("what to show"). When we write video scripts, we pull from these.

> **Naming:** "Orama Zetta" is the current working name for the product scoped in [`../`](../) as **Orama Platform — *Intelligence Velocity*** (project slug `orama-platform-2`). It's Orama's GUI + control plane wrapped around the **Orama Zetta** engine (`~/dev/homer6/zetta`).

> **Honesty note for script-writers:** these briefs describe the product *vision*. Orama Zetta's substrate (DDF API, embedded Lua, tiered storage, indexing, fused GPU kernels, heterogeneous cloud-burst backends, cloud deploy, auth) is largely **in progress** — maturity is tracked in [`../roadmap.md`](../roadmap.md) and [`../vision-and-strategy.md`](../vision-and-strategy.md) (Risks). Don't claim shipped status in a script without checking. Follow [`docs/gdrive/brain/CLAUDE.md`](../../../gdrive/brain/CLAUDE.md): no filler ("revolutionary/seamless/robust/game-changing"), lead with the outcome, not the feature.

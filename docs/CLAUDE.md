# docs/ — agent jump-table

Working documentation for the enterprise AI solution designs. Thin at this level; the
substance is one level down.

## Contents

- [`vocabulary.md`](vocabulary.md) — the governing terms **use case** (the problem) ·
  **solution** (how we solve it) · **methodology** (the arranged AI methods), with a
  worked churn example. The vocabulary every other doc uses — read it first.
- [`evidence/`](evidence/) → [`evidence/CLAUDE.md`](evidence/CLAUDE.md) — the
  **verbatim** evidence (the active area now). The capture + naming rules live in that
  `CLAUDE.md`; read it before adding evidence.
- [`prompts/`](prompts/) → [`prompts/README.md`](prompts/README.md) — the research
  prompts (Perplexity Deep Research) used to gather evidence. Each file is prompt-text
  only, copy-paste ready; the returned reports are captured under `evidence/`. All
  three vocabulary layers are covered: **methodologies**, **use-cases**, and
  **solutions** compendium prompts.
- [`plan/`](plan/) → [`plan/CLAUDE.md`](plan/CLAUDE.md) — **the portfolio plan &
  strategy** (started 2026-07-15; ⚠️ internal-confidential). The strategy kernel
  (`plan/00-strategy-kernel.md`) is **binding** — read it before editing any plan doc;
  the numbered docs (01 CEO · 02 CPO use cases · 03 CTO methodologies · 04 solutions
  catalog · 05 CMO/CRO industries+GTM · 06 CFO financials · 07 COO roadmap+risks)
  elaborate it.

_The design phase (per-solution architecture on Zetta) gets its own subfolder when we
reach it; add it to this list and to [`README.md`](README.md) when created._

## What this is

The **Orama Platform / Orama Zetta productization** project folder — the canonical
product + strategy framing for **Orama Zetta** (working product name), positioned as
*"Intelligence Velocity for Big Thinkers"* / **auto-ANI for the enterprise**: a desktop
GUI + control plane that turns a plain-language (or artifact-based) data/AI problem into
a correct, governed, deployed execution graph running on your own infrastructure — "the
platform engineer, the data engineer, and the data scientist, in a bottle."

33 markdown files: the PM scope (vision & strategy, personas, user stories, roadmap,
success metrics, ideal design partners, personalized-intelligence thesis, one-pager),
**17 audience-facing briefs** (`briefs/`), **video scripts** (`video-scripts/`), and the
**design-partner research** (`research/` — a 3-model council synthesis).

## What this is

**130 verbatim Perplexity responses** from four parallel web-research passes run on
2026-10-09, each looking for AI solutions that AI and ML engineers build for companies
(a business problem solved end to end: data → model → decision → an action in a
business system → a measurable result), beyond the solutions already in the catalogue.
Each pass took one angle:

| [`engineering/`](engineering/) | 38 | 27 ask · 1 reason · 9 research · 1 search |

## Provenance

- **Source:** the Perplexity MCP server (`mcp__perplexity__perplexity_search`,
  `perplexity_ask`, `perplexity_reason`, `perplexity_research`), four parallel research
  passes run by Claude at Steve Sperandeo's direction, 2026-10-09.
- **Captured:** 2026-10-09. Each response was saved by the research pass as it
  returned, as `NN-<tool>-<slug>.md`, numbered in call order within its angle. Each
  file opens with a header naming the tool, the exact query and the UTC timestamp,
  followed by the full response in a fenced block with its citations. The files here
  are byte-identical copies of those originals (checksums in
  [`SHA256SUMS.txt`](SHA256SUMS.txt), verified with `cmp` on capture).
- **Calls that returned nothing are not here.** The engineering pass made 41 calls;
  three `perplexity_research` calls hit a rate limit and returned no content, and were
  re-run as later calls. Only the 130 calls that returned a response were saved.
- **Query confidentiality.** Every query is generic web research. No query contains
  Orama, Zetta, Metis, the catalogue, customers, prices or any other internal material
  (checked on capture). The queries are listed verbatim below.
- **Treat figures as leads.** The responses quote vendor and company-published results;
  the response text says so where it does. Citations inside each response are the
  primary sources.
